# Algeria plastics knowledge base

Live data files updated across research phases.

- `entities.csv` — knowledge graph of Algerian companies/organisations (suppliers, molders, mold makers, machine distributors, buyers).
- `signals.csv` — classified evidence log (demand, pain, competitor, price, supply shortage, quality complaint, regulatory, technology, buyer behavior).

Confidence labels: VERIFIED, STRONG SIGNAL, WEAK SIGNAL, ASSUMPTION, UNKNOWN.
